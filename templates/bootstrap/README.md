# Bootstrap Templates (v3)

These templates drive project bootstrap ideation and seed artifact writing.

Files:
- `seed-project-docs.md`: facilitator core prompt and phase flow.
- `brainstorm-a.md` to `brainstorm-g.md`: guided ideation, convergence, synthesis, adversarial review.
- `project.tmpl.md`: `docs/design/PROJECT.md` schema and guidance.
- `requirements.tmpl.md`: `docs/design/REQUIREMENTS.md` schema and guidance.
- `roadmap.tmpl.md`: `docs/design/ROADMAP.md` schema and guidance.

Expected output artifacts from a full bootstrap run:
- `docs/design/VISION.md`
- `docs/design/PROJECT.md`
- `docs/design/REQUIREMENTS.md`
- `docs/design/ROADMAP.md`
- `docs/design/BOOTSTRAP_TASKLIST.md`
- `conductor-state.md`
- docsync handoff targets under `docs/living/`

All templates are v3-only and should align with:
- v3 sentinel contracts in `contracts/sentinel/v3/`
- skills in `skills/`
- track/task execution in `tracks/`
