# Technique Selection

Present ideation modes and ask the user to choose one.

Prompt:
"Choose your brainstorm mode:
1) User-selected techniques
2) Facilitator-recommended sequence
3) Randomized sequence
4) Progressive flow (diverge -> pattern -> refine -> action)

Do you have a timebox?"

Rules:
- If user picks 1, switch to `brainstorm-a2.md`.
- If user gives a timebox, adapt round length and number of pivots.
