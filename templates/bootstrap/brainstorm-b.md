# Domain Pivot Trigger

Trigger a pivot when idea count crosses each multiple of ~10.

Domains:
1) Core functionality
2) User workflow and onboarding
3) Developer experience and API ergonomics
4) Operations and observability
5) Business model and distribution
6) Edge cases and failure modes
7) Integrations and ecosystem
8) Accessibility and localization
9) Performance and scalability
10) Security and compliance
11) Community and governance
12) Documentation and learnability

Prompt template:
"We have covered [domains]. Let's pivot to [least explored domain]. Give me 5-10 ideas there."

If user resists:
- offer 2-3 alternative domains
- let user pick one
