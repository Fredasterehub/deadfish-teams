# `.deadfish/` Runtime Directory Contract

## Purpose
- `.deadfish/` is the canonical runtime state directory for orchestration artifacts.
- Files in this directory are machine-written, ephemeral state, and must never be committed.

## Canonical Layout
```text
.deadfish/
├── conductor/
│   └── <track_id>.yaml
├── reconcile/
│   ├── <track_id>.trigger
│   └── <track_id>.yaml
└── session/
    └── <task_list_id>/
        └── STATE_SNAPSHOT.md
```

## Path Semantics
- `<track_id>`: track slug (for example `v32-realignment`) that maps to `tracks/<track_id>/`.
- `<task_list_id>`: task-list/session identifier used by runtime hooks.
- `STATE_SNAPSHOT.md`: canonical session compaction snapshot path.

## File Schemas

### `.deadfish/conductor/<track_id>.yaml`
Conductor persistent state, updated after each evaluation.

Required top-level keys:
- `track_id` (string): track identifier for this state file.
- `phase` (string enum): `drift-check` | `reconcile` | `boundary` | `stuck`.
- `drift_log` (list): append-only drift observations.
- `deviation_log` (list): append-only guardrail/protocol deviations.
- `verdict_history` (list): append-only boundary/drift verdict records.
- `last_evaluated` (string): RFC 3339 UTC timestamp of latest evaluation.

`verdict_history` record schema:
- `timestamp` (string, required): RFC 3339 UTC.
- `decision` (string, required): `CONTINUE` | `ADAPT` | `REPLAN` | `ESCALATE`.
- `because` (list of strings, required): rationale lines backing the decision.
- `track_complete` (boolean, optional): whether all tasks were complete at evaluation.
- `base_commit` (string, optional): base commit used for boundary diff.
- `head_commit` (string, optional): evaluated `HEAD` commit.
- `notes` (list of strings, optional): additional context.

`drift_log` and `deviation_log` item schema (recommended):
- `timestamp` (string): RFC 3339 UTC.
- `type` (string): event category.
- `details` (string): short human-readable details.

### `.deadfish/reconcile/<track_id>.trigger`
Track-boundary reconciliation trigger flag written by Conductor on `CONTINUE`.

Allowed content:
- Empty file, or
- Single-line reason/timestamp text.

### `.deadfish/reconcile/<track_id>.yaml`
Track-boundary reconciliation record written by Integrator after doc reconciliation.

Required top-level keys:
- `track_id` (string): reconciled track identifier.
- `timestamp` (string): RFC 3339 UTC reconciliation completion time.
- `trigger` (string): trigger path consumed (for example `.deadfish/reconcile/<track_id>.trigger`).
- `docs_evaluated` (integer): number of living docs evaluated.
- `proposals` (mapping): per-doc proposal and outcome records.
- `docs_changed` (list of strings): docs actually updated.
- `commit_sha` (string): single reconciliation commit SHA.

Optional top-level keys:
- `debate_log` (list): full serialized multi-round debate transcript.

`proposals.<DOC_NAME>` schema:
- `action` (string, required): `UPDATE` | `NOP`.
- `debate_rounds` (integer, required for `UPDATE`): 1-3.
- `outcome` (string, required): `auto_approved` | `auto_rejected` | `escalated_to_human` | `human_approved` | `human_rejected`.
- `reviewers` (mapping, required for `UPDATE`):
  - `opus` (string): `APPROVE` | `REJECT` | `MODIFY`
  - `gpt52` (string): `APPROVE` | `REJECT` | `MODIFY`
- `human_decision` (string, optional): `approved` | `rejected`.
- `rationale` (string, optional): short summary of final decision.

### `.deadfish/session/<task_list_id>/STATE_SNAPSHOT.md`
Canonical session snapshot generated by compaction logic.

Required properties:
- Markdown text file.
- Represents latest resumable session state for `<task_list_id>`.
- Exactly one authoritative snapshot path per task list at the location above.

## Compatibility Note
- Legacy snapshot locations may exist for backward compatibility, but `.deadfish/session/<task_list_id>/STATE_SNAPSHOT.md` is authoritative.
